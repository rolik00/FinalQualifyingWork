# Выпускная квалификационная работа, 4 курс 
## "Разработка компонента генерации интерфейсов IDL"

__Цель выпускной квалификационной работы:__

Разработка компонента, который на основе языка описания интерфейсов автоматически генерирует готовый код для любого поддерживаемого языка программирования согласно заданному шаблону. Данный компонент станет частью инструментальной цепочки Eco.Toolchain и позволит значительно упростить миграцию и интеграцию унаследованного кода в экосистему ACOM.

__Документация пользователя:__

1. ___Описание приложения___

   Eco IDL — это консольная утилита предназначенная для парсинга .idl файлов и автоматической генерации исходного кода (интерфейсов, заголовочных файлов) для различных целевых языков программирования (C, C++, Java и Python). Утилита построена на базе компонентной архитектуры Eco OS. Приложение читает входной IDL-файл, строит абстрактное синтаксическое дерево (AST) и передает его зарегистрированным модулям-генераторам (эмиттерам) для создания финального кода.
2. ___Установка и настройка конфигурации___
   
   __Важное требование:__ При скачивании и установке исполняемого файла утилиты (eco-idl.exe), в эту же корневую директорию необходимо обязательно поместить конфигурационный файл config.ini.
   
   Данный файл отвечает за динамическую регистрацию языковых эмиттеров: он связывает строковые идентификаторы языков с уникальными идентификаторами COM-компонентов (UGUID) архитектуры Eco. В случае отсутствия файла config.ini утилита выдаст системное предупреждение, а генерация кода для некоторых языков может оказаться недоступной.
3. ___Использование___

   Запуск утилиты осуществляется из командной строки.
   ```
   eco-idl [ОПЦИИ]... <имя_файла.idl>
   ```
   _Доступные параметры:_
   * /HELP, -help — Вывод справочной информации по использованию программы. 
   * /lang, -lang [lang] — Выбор целевого языка генерации. Доступные значения по умолчанию: C, CPP, Java, Python, ALL. Если параметр не указан, применяется генерация для всех языков (ALL). 
   * /out, -out [dir] — Указание корневой директории для сохранения сгенерированных файлов. Если не указано, используется текущая папка (.). 
   * /tlb, -tlb — Флаг для генерации бинарной библиотеки типов (Type Library).
   
   _Примеры запуска:_
   * Генерация кода для языка C в папку ./build
   ```
   eco-idl -lang C -out ./build MyInterface.idl
   ```
   * Генерация кода для всех поддерживаемых языков в текущую директорию
   ```
   eco-idl MyInterface.idl
   ```
